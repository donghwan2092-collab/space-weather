⑤ 구글 시트 연동 (제출 데이터 자동 수집)
  1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (예: 1학년 우주기상예보 제출결과)
  2. 시트 메뉴 확장 프로그램 → Apps Script를 엽니다.
  3. 기본 코드를 모두 지우고, 위의 [Apps Script 코드 복사]로 복사한 코드를 붙여넣은 뒤 저장(💾)합니다.
  4. 배포 → 새 배포 → 유형 선택(⚙) → 웹 앱. "다음 사용자 인증 정보로 실행: 나", "액세스 권한이 있는 사용자: 모든 사용자"로 설정하고 배포 → 권한 허용.
  5. 표시된 웹 앱 URL(…/exec)을 복사해 이 HTML 파일 상단 CONFIG.GAS_URL의 "" 안에 붙여넣고 저장합니다.
  6. 파일을 다시 열고 이 패널에서 [연결 테스트]를 눌러 "✅ 연결 성공"을 확인합니다.

· 학생이 [📨 선생님께 제출하기]를 누르면 제출 시각·학생 정보·모든 응답·항목별 자동 점수·완성 대본이 시트 '제출결과'에 한 줄로 기록됩니다.
· 같은 학생이 다시 제출하면 기존 행이 새 내용으로 갱신되고 '제출 횟수'가 올라갑니다(스크립트의 OVERWRITE_SAME_STUDENT로 변경 가능). 시트의 '교사 조정 점수'·'교사 코멘트' 열은 재제출 시에도 보존됩니다.
· 전송에 실패하면 자동으로 기존 '복사 방식'으로 바뀌어 학생이 제출 내용을 붙여 넣어 보낼 수 있습니다.
